# 页面、事件与生命周期

[文档首页](/) / [应用开发](/guide/project.md)

应用进入前台、切换内部页面和退出应用是三个不同的动作。资源的拥有者需要与这些动作对应。

<!-- page-outline -->
[[toc]]

## 进入应用

JavaScript 示例的 `enter()` 读取已保存设置并建立页面。页面初始化应有清楚的错误处理：读取失败和没有已有配置是不同结果，首次运行可以使用默认值。

## 处理事件

| 回调 | 用途 |
| --- | --- |
| `enter()` | 读取设置并建立当前页面 |
| `onEvent(event, target, value)` | 处理组件激活或数值变化 |
| `onRequestComplete(request, result, payload)` | 接收异步请求结果 |
| `onPermissionResult(request, permission, state)` | 继续或结束等待授权的操作 |
| `update(now)` | 按单调时钟推进需要更新的状态 |
| `onExit()` | 处理系统返回或退出请求 |
| `leave()` | 释放应用会话持有的资源 |

`onEvent` 接收控件事件，示例通过目标组件标识决定更新哪项设置。更新界面时尽量修改对应组件属性，保持滚动位置及当前页面状态。

导航切换负责显示对应视图。离开一个临时视图时，应释放它持有的订阅和临时资源；整个应用共享的数据可以由应用会话管理。

## 退出与后台任务

`leave()` 负责清理应用会话资源。关闭页面不等于一个后台任务完成。后台运行权限允许使用系统支持的后台任务机制，任务的执行范围与生命周期由对应 API 决定。

通知权限负责发布通知。需要后台工作的应用还必须声明和取得后台运行权限，以及网络、蓝牙等实际操作所需权限。

## 异步结果

提交成功意味着请求被接收。应用通过对应完成事件检查操作结果，再更新界面或业务状态。退出后的回调归属和取消方式应以各服务的契约为准。

需要跨页面保留的请求使用应用范围，临时页面请求使用页面范围。对于页面重建后的结果，先确认请求仍属于当前页面，再访问组件句柄。文件下载等退出后继续执行的工作见[后台任务](../services/tasks.md)。
