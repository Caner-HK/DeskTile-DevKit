# 资源与语言

[文档首页](/) / [应用开发](/guide/project.md)

资源通过应用包路径访问。应用私有配置和用户主动选择的文件属于不同的数据来源，应使用各自的 SDK 接口。

<!-- page-outline -->
[[toc]]

## 图标

应用图标、桌面磁贴图标和通知图标承担不同用途。按照清单为对应位置声明资源，核对实际像素尺寸、透明区域和主题适配。

通知图标支持系统着色和保留原色两种模式，详细说明见[通知服务](../services/notifications.md)。

## 文本和字体

优先使用系统提供的字体与组件字号。应用使用专用字体时，应管理其资源和生命周期，并检查实际语言覆盖。界面中每一种状态都应具有完整文字，包括空内容、错误、禁用和操作完成。

## 本地化

项目语言文件按相同键组织。新增一个界面字段时，同步补齐对应语言的内容。使用动态参数的句子应作为完整消息处理，给不同语言保留调整语序的空间。

```js
const language = DeskTile.createI18n("locales/catalog.json");
const title = language.t("title");
```

目录声明支持的语言和默认语言，框架依据应用语言选择与系统语言读取相应消息文件。应用收到语言变化时重新读取显示文字并更新当前页面。`createI18n` 用于界面消息；大量业务内容可以按所选语言分成独立资源，在使用时读取。

## 资源读取

`resourceText` 读取文本，`resourceJson` 解析 JSON，`resourceRead` 返回字节。大资源可以先用 `resourceSize` 获取大小，再通过 `resourceReadRange` 分段读取。资源路径为包内相对路径，文件名与大小写应和清单一致。

## 检查

构建会检查资源引用和包结构。实际界面还需要在设备上检查字形、截断、换行和触摸区域。
