## 布局

| 组件 | 用途 |
| --- | --- |
| [页面](page.md) | 作为一个界面的根节点，承载应用栏和正文。 |
| [应用栏](system-bar.md) | 显示当前页面标题、返回入口和页面操作。它位于系统状态栏下方。 |
| [横向容器](row.md) | 将子组件从左到右排列，适合按钮组和一行内的标签、数值。 |
| [纵向容器](column.md) | 将子组件从上到下排列，适合页面正文、说明与表单。 |
| [层叠容器](stack.md) | 让子组件共享同一布局区域，适合叠放背景、图片与文字。 |
| [网格](grid.md) | 按列排列重复的操作或内容，让每一项保持一致的布局规则。 |
| [滚动容器](scroll-view.md) | 在限定视口中显示超出可用空间的内容。HTML 标签使用 dt-scroll。 |

## 组件与组合用法

FAB、颜色选择和菜单属于已有基础组件的组合或变体，各自提供独立用法和示例。系统键盘、系统 App Menu 与通知通过系统服务接入，参见[平台服务](../services/)。

## 原生页面与公开 SDK 的区别

| 设备已有用法 | SDK 1.0 的当前入口 |
| --- | --- |
| 圆形及切角 FAB | Button 的 circular（8）与 floating（3）变体 |
| 颜色选择 | Button 的 color-swatch（10）变体 |
| 页面操作菜单 | `ui.menu`，采用原生 PopupMenu 的尺寸和主题 |
| 系统 App Menu | `DeskTile.registerMenu` 和 `app-menu` 事件 |
| 侧栏导航 | Scaffold 的导航条目、展开与收起接口 |
| 侧边 Dialog | 原生系统已有专用绘制；公开 Dialog 当前提供 embedded 和 centered 两种呈现 |
| Radio 单选 | 原生系统已有 radio 绘制；公开组件枚举尚未提供独立 Radio |
| 文件路径面包屑 | 文件 App 的导航组合；SDK 可用 Row、Button 与 Text 组织路径 |
| 列表分组标题 | 使用 Text 与 List 组合，标题和列表属于同一滚动内容 |
