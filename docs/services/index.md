# 系统服务

[文档首页](/)

| --- | --- |

| [用户文件](files.md) | 申请读写权限，使用公开文件操作接口 |
| [网络](network.md) | 声明网络权限，关联请求 ID 与完成回调 |

## 权限

在 `manifest.json` 声明需要的权限，运行时检查授权。需要用户授权时使用明确理由请求权限，分别处理未询问、已允许和已拒绝。系统专用权限由系统控制。

私有存储是应用隔离的一部分。后台运行和通知是不同权限：后台执行由相应任务机制承接，向用户发布通知由通知权限控制。

## 异步结果

提交成功的请求返回正数请求 ID，立即失败返回具体负数错误。部分同步或已满足的操作返回 0；应按具体接口契约判断。保存请求 ID，将完成回调分派到原操作。页面离开时取消页面范围请求，应用范围请求按应用生命周期管理。

完整权限与错误枚举见 [SDK 契约](../api/contract.md)。
