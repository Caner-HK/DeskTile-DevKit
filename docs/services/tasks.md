# 后台任务

[文档首页](/) / [系统服务](/services/)

系统任务服务保存任务状态并执行支持的操作。应用页面展示进度，退出页面之后由系统继续管理任务。重新进入时通过任务列表或任务 ID 恢复显示。

## 开发步骤

1. 在清单声明操作所需权限，例如网络下载需要网络、目标文件访问及适用的后台授权。
2. 使用 SDK 任务接口提交受支持的任务，保存返回的任务标识。
3. 在进度页查询任务状态；页面离开后释放界面和页面请求。
4. 再次进入时重新查询任务，显示完成、失败、取消或执行进度。
5. 需要任务完成提醒时接入通知权限和系统的任务通知规则。

任务接口包括提交、列表、查询、取消、重试、移除和进度页呈现状态。JavaScript 的 `DeskTile.tasks` 与 Native 包装器使用相同的平台协议，具体字段以 [当前 API](../api/) 为准。

## 选择正确的执行方式

短时前台请求可以直接使用网络接口。需要退出后持续完成的下载等操作交给任务服务。后台运行权限授权的是系统支持的后台执行能力，任意 JavaScript 循环的生命周期仍由应用运行时管理。
