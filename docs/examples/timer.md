# 计时器

[文档首页](/) / [应用开发](/guide/project.md) / [应用示例](/examples/index.md)

计时器是一个 JavaScript 应用，展示时长选择、开始与停止、倒计时和逾时状态，以及退出重开后的状态恢复。

## 阅读顺序

| 文件 | 重点 |
| --- | --- |

| `src/index.html` | 时长选择器、时间显示和操作按钮 |
| `src/main.js` | 时间计算、状态转换、刷新与持久化 |
| `locales/` | 三种语言的操作及计时文案 |

## 计时状态

阅读开始、停止和恢复状态的处理，并跟踪刷新时如何计算剩余时间和逾时时长。时长选择使用系统组件，应用将用户选择转化为自己的计时状态。

主页的三个快捷时长默认是 1、5、15 分钟。每次开始新的计时，将该时长移到第一位，保留最近三个不同的时长；单纯选择时长和恢复暂停中的计时保留已有顺序。最近时长与计时状态一起保存，重新打开应用继续使用。`timer-v1` 私有记录可读取旧格式，并在下次保存时迁移到包含快捷时长的新格式。

退出重开后的恢复依赖保存的数据和重新计算。需要后台执行的独立工作时，查阅[后台任务](../services/tasks.md)；需要发布提醒时，查阅[通知](../services/notifications.md)的权限及生命周期规则。

## 实机验证

选择短时长并开始计时，检查归零和逾时显示；计时中退出并重开，确认状态恢复；停止后重新设置时长，检查按钮、数字与持久状态一致。

时长选择组件的值与事件见[时长选择器](../components/duration-picker.md)。
