# 制作图片、图标与磁贴资源

[文档首页](/) / [开发工具](/tools/)

VS Code 提供两个工具：**应用图标与磁贴**管理应用身份和桌面磁贴；**导入资源**在同一个编辑页中提供“导入图标”和“导入图像”两个 tab。两者生成设备使用的 DTI 资源，Build Application 将资源与代码打包为 `.dtapp`。

## 应用图标与磁贴

1. 打开应用项目，在 DeskTile DevKit 侧栏选择 **应用图标与磁贴**（Application Icons and Tiles）。
2. 在左侧选择应用图标、通知图标、默认磁贴图标或四种磁贴尺寸。多外观项目还可切换外观 ID。
3. 编辑图标或选择 **自定义绘制** 后，通过 **Add image** 导入 PNG、SVG、JPEG、WebP 或 DTI。可添加多张图片、文字、标题和矩形，并修改图层名称及前后顺序。
4. 拖动图层调整位置，拖动右下角控制点缩放；图片与默认图标实例按比例缩放，按住 Shift 可分别改变宽高。检查器可精确设置 X、Y、宽高、旋转、颜色和文字参数。
5. 在语言选择中编辑简体中文、繁体中文与英文应用名称、各尺寸磁贴名称及文字内容。标题图层使用磁贴名称，空名称回退到应用名称。
6. 使用浅色或深色预览背景检查边缘。100%、200%、400% 仅改变画布显示倍率，保存坐标使用设备像素。
7. **Save to project** 保存素材、构图与清单；再次打开可继续编辑。然后执行 **Build Application**。

方向键移动选中图层 1 px，Shift 加方向键移动 10 px；Delete 删除图层，Ctrl/Cmd+Z 撤销，Ctrl/Cmd+Shift+Z 重做。

完整图片经过平移、缩放和旋转后，由最终画布裁切。放大照片并移动可调整取景。每种尺寸的背景、图层、标题位置和构图独立保存。

### 两种磁贴绘制模式

**磁贴绘制** 决定整个应用的四种尺寸由谁绘制：

- **系统接管**：提供默认磁贴图标和名称。设备负责背景、图标位置、系统字体与标题。四种尺寸页面为只读预览；通过 **编辑磁贴图标** 修改同一个默认图标。保存生成 40、64、80、128 px 正方形图标，清单使用系统绘制路径，标题与背景保持由设备生成。
- **自定义绘制**：自行设计整块磁贴，包括背景、图标、文字与标题。每种尺寸可独立编辑，保存生成对应的完整静态图片，并设置 `tile.full_image: true`。

模式适用于全部外观与尺寸。切换时保留可编辑的自定义构图，撤销可恢复先前模式。已有完整图片项目打开时显示为自定义绘制。

系统接管预览沿用桌面构图：小磁贴图标居中；其他尺寸可在 **磁贴标题** 中选择 **显示标题**或**隐藏标题**。显示标题时，图标中心向上偏移 10 px；隐藏标题时，图标在磁贴中居中。

| 磁贴 | 主图标边长 | 显示标题时 X / Y | 无标题时 X / Y |
| --- | --- | --- | --- |
| 1 × 1 | 40 px | 固定无标题 | 20 / 20 |
| 2 × 2 | 64 px | 52 / 42 | 52 / 52 |
| 4 × 2 | 80 px | 132 / 34 | 132 / 44 |
| 4 × 4 | 128 px | 108 / 98 | 108 / 108 |

支持 `tile.show_title` 的 System 固件按尺寸读取标题显示设置，例如 `"show_title": {"2x2": false, "4x2": true, "4x4": false}`，该对象位于清单的 `tile` 中。未指定的大尺寸默认显示标题；1 × 1 始终为居中图标。名称留空仍按原规则回退到应用名称，隐藏标题使用独立设置。自定义完整磁贴中的文字由构图控制。

系统标题使用 32 px 系统字体，左右留白 16 px，标题区域位于底部 44 px、区域高 36 px；过长的名称显示省略号。设备按当前系统字体、语言与主题绘制。

自定义绘制中的 **使用标准排列** 可将当前画布恢复为默认图标与标题图层，作为继续编辑的起点。该操作仍属于自定义绘制；撤销可找回之前的构图。

### 默认图标与完整磁贴

默认磁贴图标是可复用的 96 × 96 构图。**Add default icon** 将它作为实例加入某一尺寸磁贴；修改默认图标会更新所有实例，各实例的位置、大小、旋转和系统着色颜色可分别调整。已有独立尺寸素材按原构图导入。

| 用途 | 画布尺寸 |
| --- | --- |
| 应用图标、默认磁贴图标 | 96 × 96 |
| 通知图标 | 32 × 32 |
| 小磁贴 1 × 1 | 80 × 80 |
| 中磁贴 2 × 2 | 168 × 168 |
| 宽磁贴 4 × 2 | 344 × 168 |
| 大磁贴 4 × 4 | 344 × 344 |

完整磁贴包含背景与标题。标题是否显示、位置及样式由构图决定，系统按生成的整块资源绘制。

### 原始素材与可编辑项目

`icon-design/project.json` 保存图层、三种语言、尺寸与外观。完整原始素材保存在 `icon-design/sources`。请将整个 `icon-design` 目录加入应用的源代码版本管理；DevKit 构建会将它排除在设备安装包之外。

旧编辑器的有效项目会迁移原始素材、颜色模式和留白。保存前修改了清单时，重新打开编辑器读取最新配置。重复保存复用当前编辑器资源目录；资源派生外观复用其已有路径。保存时保留代码、版本号与其他清单配置。

系统字体预览直接读取 DeskTile 字库及字宽，提供 MiSans（系统默认）、Cabin、Noto Sans、Source Serif 4，以及 16、20、22、32、48 px 原生字号。西文字形随所选字体变化，中文字形按系统规则回退。预览和静态导出使用同一份原生字形数据。

选择 **已安装的字体**，可输入电脑字体名称并使用 6–256 px 字号；在另一台电脑继续编辑时，应安装相同字体。构图文字按设计时选择的字体生成像素，修改字体后重新保存即可更新资源。已有完整磁贴以原始图像图层导入，便于保留构图；其内部已合成的文字可通过替换素材或新增图层修改。

## 颜色与依赖

系统着色保留透明度形状，适合单色符号；应用、通知和默认图标可选择此模式。完整磁贴始终保存构图颜色，引用系统着色默认图标的实例可设置自己的颜色。

自定义颜色导出为 RGB565 与二值透明度：透明度低于 128 的像素透明，其余像素不透明。系统着色图形保留 8 位透明度。电脑画布默认 100%，按屏幕像素密度渲染并保留平滑边缘；导出使用设备分辨率及格式。SVG 预览按完整矢量边界栅格化，原始文件保留在项目中。已有低分辨率位图的细节取决于原始素材，编辑时可导入原始 SVG 或更高分辨率图片。

```sh
python -m pip install Pillow CairoSVG
```

SVG 应自包含路径与图片；跨电脑使用的文字请在绘图工具中转成路径。

## SDK 1.0 完整静态磁贴

选择 **自定义绘制** 时，编辑器设置 `tile.full_image` 和 `icons.tile_variants`；系统接管使用正方形图标变体并移除 `tile.full_image`。以下为自定义绘制清单：

```json
{
  "icons": {
    "application": "assets/application.dti",
    "tile": "assets/tile.dti",
    "tile_variants": true
  },
  "tile": {
    "default_size": "2x2",
    "supported_sizes": ["1x1", "2x2", "4x2", "4x4"],
    "full_image": true
  }
}
```

以上路径对应 `assets/tile-1x1.dti`、`tile-2x2.dti`、`tile-4x2.dti`、`tile-4x4.dti`，尺寸见画布表。可选繁体及英文资源在尺寸后加 `-zh-HK` 和 `-en`；缺少对应语言时回退到无后缀资源。系统从实际图像读取过渡背景色，完整构图拥有背景及标题。

传统图标模式保留原有 40、64、80、128 px 正方形尺寸资源和系统标题布局。完整静态磁贴需要配套的新 System 固件与 SDK 构建工具。此能力包含在 **SDK 1.0 / Tools 2**。

## 多外观图标

应用可以通过同一个公共接口选择图标与磁贴外观。清单可声明最多 16 个内联 ID，或从资源目录派生更多外观：

```json
"appearances": { "default": "ADM", "from_resources": true }
```

此字段位于 `icons` 中，和 `choices` 二选一。ID 使用 1–16 个 ASCII 字母、数字、下划线或连字符。资源派生外观上限 256 个；安装包整体仍受 512 个文件及设备安装容量限制。

以 `assets/application.dti`、`assets/tile.dti` 为基础，ADM 的资源位于 `assets/ADM/application.dti`、`assets/ADM/tile.dti`，完整磁贴还需同目录四种尺寸资源。保留基础资源作为默认回退。可选启动图沿用相同目录规则，缺少选中外观启动图时使用基础启动图。

```js
const current = DeskTile.icons.current();
const result = DeskTile.icons.select('ADM');
if (result !== 0) {
  // Show an application-owned save error.
}
DeskTile.icons.reset();
```

```cpp
#include <desktile/icon_appearance.hpp>
char current[17]{};
auto result = desktile::sdk::iconAppearance(host, current);
result = desktile::sdk::setIconAppearance(host, "ADM");
result = desktile::sdk::setIconAppearance(host, "");
```

选择按应用隔离并持久保存，空 ID 恢复清单默认外观。调用成功后系统刷新图标缓存；资源缺失或保存失败时保留先前选择。交互预览实现相同接口与本地持久化。Calligraphy 的 43 套外观使用此规范，旧选择会迁移到公共接口。

## 导入资源

打开 DeskTile DevKit 侧栏的 **导入资源**（Import Resources）。在“导入图标”和“导入图像”之间切换时，各自保留文件、参数和预览。**保存到项目**是主操作，可直接处理当前参数并写入资源；**预览**用于先检查结果。

### 导入图标

为按钮旁、列表内容或页面中的图形导入外部素材：

1. 打开应用项目，进入 **导入资源 → 导入图标**。
2. 浏览并选择 SVG、PNG、JPEG、WebP 或 DTI 文件；源文件可位于项目外。设置项目 `assets` 目录内的输出路径。
3. 设置最大宽高。转换保持原图比例，图标输出为系统着色资源，保留形状与透明度。
4. 可点击 **预览**，检查浅色与深色背景中的结果及实际像素尺寸。
5. 点击 **保存到项目**，按当前参数生成并写入 DTI 文件；已有同名资源时确认替换。单独预览仅生成临时文件，关闭页面会清理临时文件。
6. 保存后复制 **Image 组件代码**，粘贴到页面布局中，再构建应用。

界面图标通过 `dt-image` 的资源路径加载，由系统着色。应用名称、应用图标和磁贴配置由**应用图标与磁贴**编辑器管理。

### 导入图像

1. 切换至 **导入图像**，选择源图像并设置项目 `assets` 目录内的输出路径。
2. 宽高留空时使用原始尺寸；可设置最大宽高并保持原图比例。图像按设备格式保存原色，透明度规则见“颜色与依赖”。
3. 可先预览浅色与深色背景，再点击 **保存到项目**；也可直接保存。保存后复制 Image 组件代码到页面布局。

## 命令行转换

CLI 保留快速居中转换，图层构图使用可视化编辑器：

```sh
desktile icon . --source artwork/logo.svg --purpose tile --mode system --padding 8
desktile icon . --source artwork/logo.svg --purpose tile --mode system --padding 8 --apply
desktile build .
```

`--purpose` 支持 application、tile、notification。通知权限由应用按实际用途声明。普通页面图片支持 PNG、JPEG、WebP、SVG 和 DTI：

```sh
desktile image . --source artwork/picture.png --output assets/picture.dti
desktile image . --source artwork/symbol.svg --output assets/symbol.dti --width 40 --height 40 --mode system
```

宽高参数指定最大范围并保持比例，只设置一边时另一边自动计算；已有输出使用 `--replace`。生成图片每边最多 4096 px、总像素最多 1,048,576，设备 Image 组件单张资源还受 384,000 像素上限约束。

```html
<dt-image resource="assets/picture.dti" width="320" height="180"/>
```

组件与资源保持相同比例。系统符号及其许可见[完整图标目录](../components/icon-catalog.md)。
