# DeskTile DevKit

DeskTile DevKit 是开发 DeskTile 应用的工具套件。你可以使用 VS Code 插件编写应用，也可以在终端执行构建和打包。两种入口使用同一个核心，当前 SDK 为 **1.0**。

<!-- page-outline -->
[[toc]]

## 第一次开发

从[安装开发环境](start/install.md)开始，接着[创建第一个应用](start/first-app.md)。教程会带你建立工程、修改界面、构建安装包，并在设备上运行。

## 理解应用

[项目结构](guide/project.md)解释应用包、页面和资源如何组织。[生命周期](guide/lifecycle.md)解释进入、离开、事件以及后台工作的关系。接着学习[资源与语言](guide/resources.md)。

## 设计界面

[设计指南](design/index.md)介绍系统界面的组织原则。[组件指南](components/index.md)说明怎样选择组件、组合页面，以及核对交互状态。

## 使用服务

从[系统服务](services/)选择应用需要的能力。先理解[权限](services/permissions.md)和异步结果，再接入存储、文件、网络、蓝牙、通知或后台任务。需要准确的参数和返回类型时查阅 [API 参考](api/)。

## 构建与交付

[工具指南](tools/index.md)介绍插件和 CLI。[发布应用](publish/index.md)解释开发包、签名包、权限与兼容性检查。
