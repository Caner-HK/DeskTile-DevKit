# Icon catalog

[Documentation home](/en/) / [Design and components](/en/components/)

Generated from the device `UiIcons::Id` and original assets. [Download all DTI files and licenses](/icon-catalog/icons.zip). Source SVGs are in the SDK `resources/icons/source`; IDs are in `resources/icons/catalog.json`.

## Using an icon

Copy DTI files into package assets and load them with [Image](image.md). SDK 1.0 `dt-icon` accepts IDs 0–120; JavaScript Scaffold, list and menu builders accept 0–103. Use packaged DTI resources for other icons. Preserve square bounds and choose a symbol matching the action.

```html
<dt-icon icon="28" width="40" height="40"/>
<dt-image resource="assets/Notifications.dti" width="40" height="40"/>
```
