## System surfaces and combinations

FAB and color swatches are Button variants. Page menus use `ui.menu`; [App Menu](app-menu.md) is registered with the system. Public Dialog offers embedded and centered presentations; the system also has its own side dialog. Native system radio drawing is available internally; SDK 1.0 has no standalone Radio enum. Compose breadcrumbs with Row, Button and Text, and list group headings with Text above List in the same scroll content.
